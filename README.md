# Mark's Projects

Home page for Mark's games and classroom activities, for ALTs. The student games hub is at https://nagasakimark.github.io/games/

## Adding or updating a project

Everything lives in **`projects.js`**. Copy a block, change the words, and leave one empty line between projects.

- `name`, `link` and `image` are required. `type` is `student` (also on the games hub) or `class`.
- `created:` and `updated:` (year-month-day) sort the page automatically: made in the last 14 days goes in **New**, updated in the last 14 days goes in **Recently updated**, everything else follows, most recent first.
- When you improve a project, change its `updated:` date.
- Keep the games hub and this page in step: new games, updates and new thumbnails from the hub get copied here.
